Devtron is an open-source, AI-native Kubernetes management and software delivery platform that unifies application, infrastructure, and cost management for engineering, DevOps, and SRE teams. It provides Kubernetes-native CI/CD, GitOps (ArgoCD/FluxCD), multi-cluster operations, security and compliance governance, observability, and FinOps in a single interface, with 100+ tool integrations and an agentic SRE assistant. Devtron exposes a programmable orchestrator REST API (OpenAPI 3.0, 110 operations) covering application, job, Helm chart, deployment, bulk-action, RBAC, SSO, cluster/environment and notification management, authenticated with RBAC-scoped API tokens. Backed by Insight Partners. Enriched by the API Evangelist pipeline from Devtron's public developer surface.

**Areas:** Company · DevOps · Kubernetes · CI/CD · GitOps · Platform Engineering · Software Delivery · FinOps · Observability · Developer Tools

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Devtron: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
